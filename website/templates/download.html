  2. Anywhere else, unpack the .tar.gz and run ./install.sh: it links the command into ~/.local/bin and adds Terraflux to the menu, without root.
  3. The application needs the desktop's own libraries (EGL or Vulkan, and libxkbcommon-x11 or Wayland); the command line needs none.

Other ways to get Terraflux

Build from source

Terraflux needs Rust 1.85 or later, CMake and a C++17 compiler.

git clone --recurse-submodules {{ site.repo }}.git
cd terraflux
cargo build --release

On a server or a cluster

The Linux archive runs without a desktop: the command line, the coordinator and the workers need no graphics libraries. See parallel and distributed computing.

Every release

The packages of every version, with their checksums and changes, are on the releases page.
