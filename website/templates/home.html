Open-source software for landscape ecology

See a landscape change, cell by cell, and know why.

Terraflux is a free desktop application and command line for habitat patterns, connectivity, spatial prioritization, species distributions and land change simulation. You build an analysis by connecting nodes, and it gives the same numbers as the tools you would cite.

The same numbers as the tools you cite

Terraflux re-implements established methods from their publications and source code, and its test suite checks each one against the reference implementation, most of them to the last bit. A reviewer who knows FRAGSTATS or Zonation will find the same results.

An analysis is a graph you can read

Each step is a node: read a map, reclassify it, run MSPA, plot the result. You connect an output to an input, and Terraflux checks that the two fit. Change a setting and only what depends on it runs again, so the map updates while you think.

  • Every node carries a note saying why it is there, so a model explains itself to a colleague.
  • The graph is a small text file: keep it under version control and publish it with your paper.
  • The same file runs in the application, from the command line, on a cluster and from Python.

Ask for the analysis, watch it being built

Connect an AI assistant to Terraflux and describe what you want in plain words. The assistant adds the nodes, connects and sets them, checks the model and runs it, and the graph grows on your canvas as it works. Undo any step with ctrl+Z, or change it by hand.

  • Every edit passes the same checks as yours: a connection that does not fit is refused, with the reason.
  • Terraflux runs on your computer. The assistant receives the model and the summaries it asks for, not your maps.
  • The result is an ordinary model file that runs again without the assistant.

From a laptop to a cluster, without rewriting anything

Run fifty replicates on the cores of your laptop, lend the lab's computers to a calibration with a pairing code, or send five hundred scenarios to your university's Slurm cluster. The model stays the same file. Maps larger than memory run in tiles, with the same result whatever the number of machines.

Open science, open source

Terraflux is free software under the GPL. Its methods are documented with the papers they come from, its results are tested against the reference implementations, and every model is a text file that can be published beside the paper that used it.
