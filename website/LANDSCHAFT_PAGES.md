may be lost) and the **source of the redirects** (old URL -> new URL). It lives in `website/`, outside `website/content/`,

Old site (A): `C:\Users\eduar\Documents\dev\landschaft-rename\docs` (nav in `mkdocs.yml`), published at
`https://sacridini.github.io/landschaft/<path>.html` (`use_directory_urls: false`).
New site (B): `website/content`, published at `https://sacridini.github.io/terraflux/`.

## URL scheme of B (read from `website/build.py`)

- **Directory URLs with a trailing slash.** `Page.__init__`: `content/a/b.md` -> `/a/b/`; `content/a/index.md` -> `/a/`;
  the file written is `<out>/a/b/index.html`. There is no `.html` in B's URLs.
- A tutorial page is `content/tutorials/<category>/<slug>.md` -> `/tutorials/<category>/<slug>/`, and its category must be
  one of `tutorial_categories` in `site.yaml` (all the categories used below already exist there).
- The first path part is the page's *section* (`Page.section`): it drives the sidebar (the section's pages, sorted by
  `order` then title) and prev/next. `site.yaml: sections` names the sections known today (quickstart, calculators,
  parallel, cli, about, glossary): **`python` must be added there** (and to `nav`) - a shared-file edit.
- Internal links are written absolute (`/about/citing/`) and `relativize()` makes them relative at build; `{{version}}` is
  replaced in text. Images go to `website/static/img/...` and are referred as `/img/...`.
- Redirect form: A `learn/metrics.html` -> B `https://sacridini.github.io/terraflux/tutorials/landscape-metrics/` (the `redirect target` column). Anchors survive only
  where the heading text (and so the slug, `slugify_unicode`) is unchanged; A used mkdocs' toc extension, whose default slug rule is close but not identical (not verified): check anchors when writing.
- B's URLs are used below without the host. The content file is relative to `website/`.

## Status legend

- `new`: a page to write in B (moved from A, adapted to B's style).
- `merge`: the content goes into an existing B page (named); the old URL redirects there.
- `covered`: B already says it all (the B page is named and what was compared is said). In the DOCUMENTATION.md table,
  `covered` means covered by another row of this mapping (an A page that is itself moved), so nothing extra is written.
- `drop`: not moved, with the reason.
